# Korely Agent documentation

- [Time: what was true, and what the store knew](time.md): put the clock back to any date and read what was true then, and what the system knew then.
- [Install](install.md): from an empty Debian or Ubuntu machine, or a laptop, to a store that has learned its first fact.
- [Talking to it: REST, MCP, SDKs and the shell](api.md): the ways an agent or a script reaches the memory, the errors it gets back and what every door refuses.
- [Webhooks](webhooks.md): endpoints that are told when something happens, and how to check the signature of a delivery.
- [Keys and account limits](keys-and-limits.md): when API keys expire, and how many keys, names and projects an account can have.
- [What is in the box: facts, audit trail, erasure](data-and-privacy.md): what is stored, what the audit trail keeps and how an end user's data is erased.
- [Keeping it running](operations.md): updates, your own proxy, the database's log, backups, what the worker trims and how to go back a version.
- [The facts, as files you can read](facts-as-files.md): the export directory where every fact is a plain file.
- [When something is wrong](troubleshooting.md): what to look at first when the service does not behave.
- [Honest limits and known issues](limits.md): what this does not do well, measured, and what is known to be broken in this version.
